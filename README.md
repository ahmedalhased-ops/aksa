# متجر AKSA — الكود المصدري

نظام متجر إلكتروني كامل: Next.js + Supabase (قاعدة بيانات + مصادقة + تخزين) + نشر على Vercel.

## ✅ الجاهز حاليًا

- **قاعدة بيانات كاملة** (`supabase/schema.sql`): ماركات، فئات، منتجات، **ألوان/متغيرات بمخزون مستقل لكل لون**، طلبات.
- **حماية على مستوى الصفوف (RLS)**: الزوار يقرؤون المنتجات المنشورة فقط، ولا أحد يقدر يعدّل السعر/المخزون مباشرة — التعديل فقط عبر لوحة تحكم الأدمن (بعد تسجيل الدخول) أو دالة `place_order()` الآمنة عند الشراء.
- **حماية من البيع الزائد**: `place_order()` تتحقق من المخزون الحقيقي وتخصمه بشكل ذري (atomic) وقت الطلب — يستحيل عميلين يشترون آخر قطعة بنفس الوقت.
- **متجر للزوار**: صفحة رئيسية، صفحة تسوق بفلاتر (ماركة/فئة/جنس) وبحث وترتيب، صفحة منتج مع اختيار اللون والكمية وعرض المخزون المباشر، سلة، وصفحة إتمام طلب تنتهي بتأكيد عبر واتساب.
- **لوحة تحكم أدمن** (`/admin`): تسجيل دخول، قائمة منتجات مع تنبيه "على وشك النفاد"، إضافة/تعديل/حذف منتج وكل ألوانه وكمياته، عرض الطلبات.
- **متجاوب بالكامل**: تصميم مختلف فعليًا للموبايل (شريط تنقل سفلي ثابت) عن الديسكتوب (هيدر علوي كامل).

## ⏳ ناقص / الخطوة القادمة

- **الصور الحقيقية**: البيانات التجريبية (`supabase/seed.sql`) بدون صور — تحتاج رفعها لـ Supabase Storage (خطوات بالأسفل).
- **تسجيل حساب عميل** لم يُبنى (الطلب حاليًا بدون حساب، زي أي متجر بسيط — يتوافق مع طلبك الأصلي).
- **بحث/فرز متقدم إضافي**، صفحات ماركة/فئة مستقلة بروابط SEO — يُضاف تباعًا.

## 1) إنشاء حساب Supabase (قاعدة البيانات)

1. روح [supabase.com](https://supabase.com) → **Start your project** → سجّل بإيميلك (مجاني).
2. اضغط **New project** → اختر اسم (مثلاً `aksa-store`) وكلمة مرور لقاعدة البيانات (احفظها).
3. بعد ما يجهز المشروع (دقيقة تقريبًا)، روح **Project Settings → API** وانسخ:
   - `Project URL`
   - `anon public` key
   - `service_role` key (**سري — لا تشاركه مع أحد ولا تحطه بكود الواجهة**)
4. روح **SQL Editor → New query**، الصق محتوى ملف `supabase/schema.sql` كامل واضغط **Run**.
5. كرر نفس الشي مع `supabase/seed.sql` (بعد `schema.sql`) لتعبئة بيانات تجريبية.
6. **إنشاء حساب الأدمن**: روح **Authentication → Users → Add user** → أدخل إيميلك وكلمة مرور. هذا الحساب هو اللي تسجل فيه دخول على `/admin/login`.
7. **رفع الصور**: روح **Storage → New bucket** → اسمه `products` وفعّل **Public bucket**. بعدها ترفع الصور من هناك مباشرة أو من لوحة التحكم، وتاخذ الرابط العام وتحطه بحقل "رابط الصورة" لكل لون.

## 2) إنشاء حساب Vercel (الاستضافة)

1. روح [vercel.com](https://vercel.com) → **Sign Up** → الأسهل تسجل بحساب GitHub (لو ما عندك، أنشئ حساب GitHub مجاني أول من [github.com](https://github.com)).
2. ارفع مجلد المشروع هذا لمستودع GitHub جديد (أو خبرني وأساعدك تسوي `git init` و`git push`).
3. من Vercel: **Add New → Project** → اختر المستودع.
4. بقسم **Environment Variables** ضيف:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   (القيم من خطوة Supabase فوق)
5. اضغط **Deploy**. بعد دقيقتين يصير عندك رابط حقيقي زي `aksa-store.vercel.app`.

## 3) التشغيل محليًا (اختياري)

يحتاج [Node.js](https://nodejs.org) مثبّت على جهازك (غير مثبت حاليًا). بعد التثبيت:

```bash
cp .env.local.example .env.local
# عبّي القيم الثلاث بالملف
npm install
npm run dev
```

الموقع يفتح على `http://localhost:3000`.

---

بعد ما تجهز الحسابين وتعطيني القيم (أو تخبرني إنك خلصتهم)، أكمل معك: أستورد بيانات المنتجات الحقيقية، أساعدك ترفع الصور، وننشر النسخة الأولى.
